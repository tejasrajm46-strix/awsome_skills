# Document design rules

Use a clear reading order: title and scope, summary, evidence, interpretation,
limits, conclusion, sources. Give each section a descriptive heading.

- Use actual Word Heading styles, not manually bolded body paragraphs.
- Keep body at 11pt and captions at 10pt. Use installed Calibri/Arial/Segoe UI.
- Use a single accent, dark text, and light callout fills; check 4.5:1 contrast.
- Write short paragraphs. Explain technical terms at first use.
- Cite substantive factual claims with stable numbered source IDs.
- Distinguish the age of a fossil, observed species range, and inferred split.
- A first/last fossil is not the exact origin/extinction date of a species.
- Avoid an image-only report. Explain every figure in adjacent editable text.
- Give images alt text and captions; say when a diagram is selective or not to scale.
- Use real table headers and repeat them. No decorative tables for page layout.
- Keep headings with following text and prevent table rows from splitting.
- Add page numbers, document title metadata, and a short running header.
- Use intentional page breaks sparingly; rendering is the pagination truth.
- Inspect every rendered page. Structural validation cannot see line wrapping,
  widows, hidden text, image clipping, or a nearly empty final page.
- Never invent a source, quotation, measurement, certainty, or a review result.
